# Final model definitions

The source release reports local paper-based reconstructions. Missing author code and ambiguous formulas are disclosed rather than resolved using official test outcomes.

* CNN-LSTM + wcMMD: PatternII wcMMD, Eq8 first weighted-kernel equality. Conditions use1cluster on FD001/FD003 and6 on FD002/FD004, fitted only on source fitting-engine operating settings. Window condition is the final-cycle condition; domain priors use all eligible windows. Empty-window engines are skipped exactly as in the window generator. The five-scale Gaussian kernel, bandwidth, regression loss, optimizer, network, cap125 and validation selection are unchanged. Single-condition wcMMD is theoretically ordinary MMD; numerical differences do not demonstrate a condition-weighting benefit. Other network/preprocessing ambiguities remain, including the within-window recurrent interpretation.
* PI_STHNN: replace only final fusion by softmax over the concatenated1024features. Keep the trained Kaiming query initialization, TPA sigmoid, graph-readout sigmoid, long windows35/60/54/80 and condition-normalization recipe. The paper's vector attention notation does not resolve the unequal feature-block dimensions. This is the adopted softmax interpretation, not confirmation of all author attention semantics. The required binary physical graph support was reconstructed from Figure5; continuous grey-relation weights are estimated from fitting data. The final graph is symmetrized by maximum, an explicit local assumption.
* ASTHGNN: retain the existing per-subset recipe and FD004 length-based expert route. Training seed dispatch is corrected. FD001/FD004 use the completed independent five-seed retraining. FD002/FD003 retain their already correctly seeded final runs. No historical internal seed42 weight is reused for a different requested seed.
* STFA: ordinary nn.LSTM, fourteen self loops, the existing additive multi-head GAT and ASE. Select minimum source-validation RMSE over30epochs, not the final epoch. The paper's cell-to-gate connections are not in this adopted local version; the separately tested dense cell-map interpretation trained unstably and is excluded from the final release. Effective single LSTM bias remains learnable.
* STHNN: retained validation-selected final recipe and its fitting-only preprocessing. No model correction in this migration.

Each subset uses its published/frozen local training budget and source-validation selection. Training splits and preprocessing differ across models; a common terminal evaluation does not mean identical training protocols. All five models use the common seeds3407,2024,137,123,12345 after eight fresh seed3407 corrections. Training protocols remain model-specific.
